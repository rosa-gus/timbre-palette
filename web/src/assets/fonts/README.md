# IBM Plex Mono retry glyph

`ibm-plex-mono-retry.woff2` contains the Regular (400) U+21BB clockwise
open-circle arrow. The standard Google Fonts Latin subset omits this glyph.
The local face is limited to U+21BB in `styles/tokens/typography.css`.

Source: [Google Fonts subset](https://fonts.googleapis.com/css2?family=IBM+Plex+Mono:wght@400&text=%E2%86%BB&display=block).
Upstream: [IBM Plex Mono](https://github.com/google/fonts/tree/main/ofl/ibmplexmono).
